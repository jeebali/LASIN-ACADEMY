IMPORTANT
Keep the folder structure exactly as supplied. Do not move files out of the lessons folders, because Exercise 02 and Exercise 03 load their audio/images with relative paths.

GITHUB PAGES
1. Upload the CONTENTS of this folder to the root of your GitHub repository.
2. Confirm index.html is in the repository root.
3. In GitHub: Settings -> Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose your main branch and / (root), then Save.
6. Open the GitHub Pages URL after deployment finishes.

WHY THIS VERSION IS GITHUB FRIENDLY
The previous single HTML was about 53 MB because all Exercise 02/03 media was embedded as data URLs. This build keeps the same lesson/scoring behavior but stores those media files separately. No individual file in this package approaches GitHub's large-file limit. The main index.html is intentionally small and lessons are loaded lazily only when opened.

SCORING
96 scored questions. Maximum 480 points. Exercise 01 = 1-24, Exercise 02 = 25-48, Exercise 03 = 49-72, Exercise 04 = 73-96.

AUDIO GATE
For every compulsory-listening question/stage, answer controls are disabled until the required audio has completed successfully. The motivation timer starts/resumes only when answering becomes available. If browser autoplay is blocked, the task remains locked and the student must tap the headphone/listen button first. Optional replay after unlocking does not reset the scoring timer.
